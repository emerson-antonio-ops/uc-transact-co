Act 0 · the reality

The gap is not the model alone

A capable model is necessary. Reliable work appears only when the environment can answer back.

What actually works
01
A bounded task
Objective, authority, evidence and stopping conditions are explicit.
02
Curated, current context
The smallest high-signal set is loaded when the work needs it.
03
Narrow tools and authority
Actions are least-privilege, observable and recoverable.
04
Independent proof
Evals, telemetry and human checkpoints judge the outcome.
What quietly does not
01
An open-ended mandate
“Make it better” hides ownership, scope and the definition of done.
02
A context dump
Stale instructions and irrelevant detail compete for attention.
03
Broad access
One plausible tool call becomes an irreversible side effect.
04
Self-declared success
A fluent answer grades the same trajectory that produced it.
The model supplies capability. The system supplies reliability.

Prompt → Context → Harness → Agentic

Every rung assumes the one below already works

Rung 1
Prompt
The right instruction. Objective, constraints, evidence and output shape.
define the work
↗
Rung 2
Context
The right information. Specs, rules, examples, memory and live evidence — deliberately selected.
supply the world
↗
Rung 3
Harness
The right system around the model. Tools, permissions, sandbox, state, recovery and independent checks.
give it hands and brakes
↗
Rung 4
Agentic
All of it inside a controlled loop. The system acts, observes and retries; evals judge; humans retain authority at the gates.
operate the discipline
You can only skip a rung once

A demo can borrow what it forgot. Production pays the debt on every run.

The system · in rings

The model is the core. The engineering is the rings.

Take one away and you lose a guarantee. The outer ring gives every loop a common language.

Graph carries shared meaning.

Entities, relationships, rules, provenance and precedent — the shared meaning and decision lineage every loop resolves against.

Eval + human gates now own acceptance, authority, escalation and accountability.

Context graph is an emerging industry term, not a settled standard. Sources: Anthropic evals · AWS Context · W3C Context Graphs Community Group.
